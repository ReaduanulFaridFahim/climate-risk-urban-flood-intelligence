Developer Reference
Launch Streamlit Directly via Terminal

.\.venv\Scripts\python.exe -m streamlit run web/app.py --server.port 8501 --server.headless true

Runs headless on port 8501 with bi-directional WebSocket streaming enabled.
Launch FastAPI Gateway Server

.\.venv\Scripts\python.exe -m uvicorn api.main:app --host 127.0.0.1 --port 8000

Serves REST endpoints, master static portals, and automatic redirection to Streamlit at /streamlit.
